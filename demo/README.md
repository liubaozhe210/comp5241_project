# CourseHub — 界面原型（Demo）

在线教学系统的**可点击界面原型**：没有后端，数据是模拟的，用来确认整体界面与操作流程是否合理。

## 打开

双击 `index.html` 即可，不需要 `npm install`、不需要 Python、不需要联网。

### 深链（方便分享某个视角）

```
index.html?user=u_s1            # 直接以该身份进入（也可用学号/邮箱）
index.html?user=u_t1#/teacher/c1
index.html?user=u_admin#/admin/audit
```

> 说明：原型没有后端，登录状态本来就存在 localStorage 里，所以 `?user=` 只是省掉手点登录，不涉及任何真实鉴权。

## 建议的查看顺序

1. 学生 → 课程目录 → 点 COMP5421（未选课）：课件区是**锁住的**

4. 回到学生：课件出现 → Preview（模拟 PDF 阅读器）/ Download

8. 学生 → **AI 模拟面试**：从专项练习入口选择简历评估、简历押题、薪资谈判、综合面试或错题复习；简历支持粘贴文本或上传 TXT、Markdown、DOCX 文件

## 视觉与技术

- **AI 模拟面试原型**：专项练习包括简历评估与修改建议、基于简历的面试问题和回答建议、薪资谈判、岗位综合面试及历史错题复习。简历文字可直接粘贴，或在浏览器本地读取 TXT、Markdown、DOCX 文件；评估和押题目前由前端本地规则模拟，不会调用真实 AI，也未实现后端。综合面试按岗位、经历阶段、专业背景与技能组合生成题目；错题识别按本地回答长度规则标记，并非正确性判分；历史错题保存在当前浏览器的 localStorage 中
- **玻璃拟态 3D 封面**：`tools/generate-covers.py` 用 numpy 写了一个 SDF 光线步进渲染器 —— 玻璃材质走「折射方向采样环境 + 三通道色散 + 菲涅尔 + 高光 + 边缘光」，另有象牙陶瓷哑光球做对比；场景是象牙白影棚（渐变背景 + 阴影捕捉面 + 柔光箱）。9 张封面（6 门课 + 3 张通用）每张换一套配色与环位，同一套光照保证风格统一
- **3D 倾斜**：课程卡片随指针做透视旋转（CSS 变量 + `pointermove`）
- **图标**：全部为内联 SVG 精灵（`icons.js`），**全站零 emoji**
- **配色**：象牙白底 + 单一强调色（墨蓝 `#1e3a6e`），语义色（红/黄/绿）只用于状态，不与强调色混用；标题用衬线字体（Iowan / Palatino / Georgia 回退），正文用系统无衬线

## 自检

```bash
node smoke-test.mjs     # 页面渲染、权限、注册、课程流程、面试生成与交互、无 emoji
node check-i18n.mjs     # 中英词条 key 完全一致、代码引用的 key 都存在
```

两个脚本都是零依赖，直接 `node` 运行。

## 重新生成封面

用 Anaconda 环境（或任意装了 numpy + Pillow 的 Python）：

```bash
python tools/generate-covers.py                 # 全部（约 6 分钟）
python tools/generate-covers.py --only c1 --ss 1.0   # 只渲染一张，调试用
```

修改 `TINTS` 里的配色即可换整套视觉基调；`build_scene()` 控制物体摆放与材质。

## 个性化学习路径

功能范围、自动检查结果与待手动确认的视觉项目见 [静态原型验收说明](ACCEPTANCE.md)。

- 学生侧栏 → **我的学习路径**（`#/learning-path`）。也可从「我的课程」进入，或在已发布课程详情点击「规划这门课的学习路径」，预填课程与主题。
- 填写主题、目标、当前水平和总学习时长（1–200 小时，半小时递增），可选关联现有课程；初学、有基础、进阶分别生成 5、4、3 个阶段。各任务时间之和等于总预算，应用阶段获得更多学习时间。
- 每个阶段展示关联课程、学习与练习任务、目标及预计时间。未主动选课时，模拟服务按主题和目标匹配最多两门已发布课程；没有匹配时明确提示使用自有资料，不创建虚构课程。选课审批规则保持不变。
- 第一阶段默认展开，其他阶段默认收起；支持逐阶段切换和全部展开/收起。展开状态在页面会话内按学生和计划版本隔离，切换语言或更新任务后保持；“继续学习”自动展开目标阶段。
- 阶段包含学习与练习任务；支持完成/撤销、阶段与整体进度，以及继续首个未完成阶段。课件访问仍遵循选课审批规则，打开 PDF 不会自动计为学完。
- 每阶段可进行本地示例知识测验。题库覆盖软件工程、数据挖掘、计算机视觉和分布式系统，按主题或关联课程选择；未覆盖主题明确回退到学习方法自测。每个题库三道人工编写的基础题，各阶段复用，不从 PDF 提取、不调用 AI，也不代表全面能力评估。
- 提交后展示分数、所选答案、正确答案、解析与知识点；保留历次答案和成绩，切换中英文保留未提交选项。旧版只有分数的学习方法记录仍可读取并明确标记来源。
- 0–1 分建议复习、2 分建议补充练习、3 分且阶段任务全部完成后建议进阶。点击「应用学习建议」分别新增 15 分钟复习、20 分钟练习或 30 分钟挑战任务，保留已有完成状态，并记录建议来源和应用时间。相同测验结果不可重复应用，存在同类未完成任务时也不重复新增。
- 新增任务计入阶段和总体进度，因此应用建议后完成百分比可能下降；原始时间预算保持记录，页面显示额外时间和调整后的预计总时长。测验得分不会自动标记任务完成。
- 修改目标会生成新版本，新版本从零记录进度，旧版本只读保留；每次自测记录也会保留。
- `learning-path-service.js` 是独立、无网络请求的模拟生成服务，输入为目标及课程上下文，输出为计划数据；`learning-path.js` 负责存储和页面，`learning-path.css` 沿用全局主题，词条位于 `i18n.js`。数据按学生存于 `coursehub.demo.learningPaths.v1.<userId>`；旧计划无需重置。设置页重置演示数据也会清除学习路径。
- 生成服务专项测试：`node --test demo/learning-path-service-test.mjs`（在仓库根目录运行）。现有回归测试：`node demo/smoke-test.mjs`、`node demo/check-i18n.mjs`。
- `learning-path-assessment.js` 封装本地题库、评分与应用建议逻辑；专项测试：`node --test demo/learning-path-assessment-test.mjs`。新任务、测验与调整沿用按学生保存的学习路径数据，旧计划无需重置。
- 生成采用本地模板，未连接真实 AI、后端或其他成员的互动课程测验；不能跨浏览器同步。存储失败时提示并退化为页面会话内存。目标表单和未提交测验选项在页面会话内保留，便于切换语言。

## 其他已知边界

- 没有真实后端：数据存 localStorage，「设置 → 重置演示数据」可恢复初始状态
- 面试题和反馈使用浏览器内置模板 / 规则模拟，不会调用外部 AI，也不会上传个人背景或回答
- 上传只记录文件元信息，不真的存文件；PDF 预览是绘制的占位页
- 未做：邮件通知、分页、课程公告（P1）
- 正式实现时应把本原型的组件与信息结构搬到 Next.js，并把数据层换成 FastAPI + Supabase
