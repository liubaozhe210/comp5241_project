## 自动化验收

`tests/test_learning_path_acceptance.py` 连续执行：

1. 保存草稿并生成两阶段计划，读取绑定页码；打开阅读页不会完成任务。
2. 完成阶段一任务，生成五题测验，提交低分；重复提交返回同一成绩。
3. 查看并应用复习建议；重复应用不会新增重复任务，原进度保留。
4. 完成补充任务，生成新一轮测验；历史题目与低分保留，新轮次通过。
5. 全部任务完成但阶段二未测验时，任务进度为 100%，计划仍未完成。
6. 阶段二测验通过，列表、详情、版本历史与阶段摘要一致显示完成。
7. 新版本生成失败保留旧计划；新版本成功后，旧版本仍能读取，禁止修改旧任务、提交旧测验。
8. 其他学生不能读取该计划；教师不能调用学生专用接口。

完整测试命令：

```text
backend: .venv\Scripts\python.exe -m pytest -q -p no:cacheprovider
frontend: npm.cmd run typecheck
frontend: npm.cmd run test:learning-path
```

自动化结果：后端 142 项通过；前端 18 项通过；TypeScript 类型检查通过。
这些结果不代表真实 AI 生成质量、MySQL 并发或生产负载测试已通过。
